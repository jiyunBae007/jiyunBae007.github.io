# jiyunBae007.github.io

Personal academic homepage of Jiyun Bae, served by GitHub Pages at https://jiyunbae007.github.io/.

Single static page (`index.html`), no build step.

- Publications: edit the `.pub-item` blocks in `index.html`. Add the `selected` class to show an entry under the default **Selected** view; entries without it appear only under **All**. `?view=all` / `?view=selected` in the URL preselects the tab.
- Assets: `assets/jiyunbae.jpg` (profile photo), `assets/cv_jiyunbae.pdf` (CV).
